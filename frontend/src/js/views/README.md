# Views

One module per route. Views compose components inside a layout — no reusable business logic here.

Planned structure:

- `public/` — `home`, `about`, `services`, `how-it-works`, `testimonials`, `faq`, `privacy`, `legal`, `login`, `register-patient`, `register-professional`, `not-found` (Module 7)
- `patient/` — `dashboard`, `profile`, `appointments`, `calendar`, `symptoms`, `treatments`, `medications`, `routines`, `assistant`, `notifications`, `settings` (Module 8)
- `professional/` — `dashboard`, `profile`, `patients`, `patient-detail`, `calendar`, `observations`, `treatments`, `medications`, `routines`, `notifications`, `settings` (Module 9)

Naming convention: `view-name.view.js`.
