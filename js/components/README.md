# Components

Reusable, isolated UI components. Views compose these — no business logic here. Each component is a module exporting a render function (and optional event binding).

Planned components (implemented across Modules 6-9):

`Navbar`, `Footer`, `Sidebar`, `Button`, `Input`, `Card`, `Modal`, `Accordion`, `Toast`, `Table`, `Pagination`, `EmptyState`, `Loader`/`Skeleton`, `SectionTitle`, `Calendar`, `StatisticCard`, `AppointmentCard`, `MedicationCard`, `SymptomCard`, `PatientCard`, `Timeline`, `FilterPanel`, `Breadcrumbs`.

Naming convention: `component-name.component.js` (kebab-case files, PascalCase exports).
